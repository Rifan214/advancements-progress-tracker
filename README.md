# Advancements Progress Tracker

A lightweight, modern Minecraft Fabric mod that makes advancement progress fully detailed, informative, and explorable — especially for multi-criteria advancements like **Adventuring Time**, **Monsters Hunted**, and more.

## Features (Planned & In Progress)
- **Detailed Advancement Progress**: View completed and remaining criteria with meaningful names instead of cryptic internal IDs.
- **Generic Criterion Resolver**: Automatically resolves biomes, mob entities, items, locations, and more.
- **Lightweight & Modern UI**: Clean visual hierarchy, progress bar, counters, scrolling, search, and filtering.
- **Existing World & Multiplayer Compatibility**: Seamlessly loads existing progress from vanilla advancement synchronization without modifying save data.
- **100% Client-Side**: No server mod or custom network protocol required. Works on vanilla and modded servers.

## Requirements
- **Minecraft Java Edition**: `26.2`
- **Fabric Loader**: `0.19.3`+
- **Fabric API**: `0.161.0+26.2`+
- **Java**: `25`

## Development
- Build: `./gradlew build`
- Run Client: `./gradlew runClient`
